# Скрипт делает скриншоты каждые 10 секунд. До двух мониторов.

Cкрипт создает подпапку `sshots`, в ней подпапки для каждого дня с именами типа `2026-03-21`

Cкринноты создаю с именами файлов типа `shot 2025-12-18 130506.jpg`

## Требования
 - AHK v1
    
 - Опционально для конвертирования в видео: python, ffmpeg

## Использование
### Установить [AutoHotkey](https://www.autohotkey.com/).

### TakeScreenshotLoop.ahk
Можно запускать скрипт вручную по необходимости или добавить в автозапуск.

### Добавить в автозапуск
Скопироавть файл `TakeScreenshotLoop.ahk` или ярлык в папку `%ProgramData%\Microsoft\Windows\Start Menu\Programs\StartUp`.

 - Найти файл в провдоднике, отметить, нажать Control+C.
 - Нажать Win+R, откроется окно запуска команд (Run dialog), набери `shell:startup` и кликни OK или нажми Enter. 
Откроется папка автозапуска текущего пользоавтеля.
Чтобы открыть папку автозапуска для всех пользователей набери `shell:common startup` (для этого нужны права админитстратора).
 - Удерживая клавишу Shift кликнуть правую мыши и кликнуть на "Paste Shortcut". Должен появиться соответвующийй ярлк.
 
 Windows 11 All Users. Папка автозапуска для всех пользоввателей: `%ProgramData%\Microsoft\Windows\Start Menu\Programs\StartUp`

 Windows 11 Current user. Папка автозапуска текущего пользователя: 
 `%AppData%\Microsoft\Windows\Start Menu\Programs\Startup`

### Конвертирование изображений в видео `make_video.py`

Проходится по всем подпапкам папки `sshots`. В каждой создает видеофайл `!output.mkv` из скриншотов. Один скриншот на одну секунда.
В видео вшиты субтитры с именеми файла изображения.

Все изобжражения и технические временные файлы(файл субтитров, конфиг переименований) после работы программы остаются на месте.

файлы:
- `!output.mkv` - видео файл
- `!output.srt` - временный файл субтитров
- `!renaming_map.json` - временный файл переименований.
