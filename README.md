# Скрипт автоматических скриншотов

Этот репозиторий содержит AutoHotkey-скрипт для периодического снятия скриншотов и вспомогательный Python-скрипт для сборки видео из сделанных изображений.

Кратко:
- Скрипт делает скриншоты (по умолчанию — каждые 10 секунд).
- Поддерживается до двух мониторов (см. замечание ниже про расчёт области экрана).
- Скриншоты сохраняются в папку `sshots\` в подпапки по дате, например `sshots/2026-03-21`.
- Формат имени файла по умолчанию: `shot YYYY-MM-DD HHMMSS.jpg`, например `shot 2025-12-18 130506.jpg`.

## Требования
- AutoHotkey v1 (рекомендуется AutoHotkey v1.1+).
- Для конвертации в видео: установленный ffmpeg (ffmpeg должен быть доступен в PATH).
- Для конвертации в видео через python скрипт: Python 3.6+ (из-за f-строк и pathlib) 

## Файлы
TakeScreenshotLoop.ahk` — основной AHK-скрипт для снятия скриншотов.
- `make_video.py` — Python-скрипт для обхода подпапок в `sshots/` и сборки `!output.mkv` из изображений одной подпапки.
- `make_video.exe` — скомпилированная версия `make_video.py` для Windows. Можно запускать без установки Python.


## config.json

Проект содержит загрузку и сохранение конфигурации в `config.json`. Поведение реализовано так, чтобы работать и с исходным `make_video.py`, и с упакованным `make_video.exe`:

- `config.json` хранится в папке приложения (APP_DIR): рядом с `make_video.py` при обычном запуске, или рядом с исполняемым файлом при запуске из PyInstaller (`sys.frozen`).
- Если `config.json` отсутствует, первый запуск `make_video.py` или `make_video.exe` создаёт файл с настройками.
- `config.py` содержит логику поиска ffmpeg: сначала ищет `ffmpeg.exe` рядом с программой, затем — в PATH; если не найден, возбуждает исключение.

Основные ключи и значения по умолчанию (они определены в dataclass Config в `config.py`):
- `dir_shots` (string) — папка со скриншотами, по умолчанию: `"sshots"`.
- `file_video` (string) — имя выходного видеофайла, по умолчанию: `"!output.mkv"`.
- `file_srt` (string) — имя временного файла субтитров, по умолчанию: `"!output.srt"`.
- `file_renaming_map` (string) — имя временного файла карты переименований, по умолчанию: `"!renaming_map.json"`.
- `files_mask` (string) — шаблон изображений, по умолчанию: `"*.jpg"`.
- `ffmpeg` (string) — путь и имя локального ffmpeg, по умолчанию: `"ffmpeg.exe"`.
- `ffmpeg_video_encoder` (string) — encoder для ffmpeg, по умолчанию: `"libx264"`.
- `ffmpeg_input_framerate` (int) — входная частота кадров (сколько изображений в секунду показать), по умолчанию: `1`.

Пример содержимого `config.json` (примерный):

```
{
  "dir_shots": "sshots",
  "file_video": "!output.mkv",
  "file_srt": "!output.srt",
  "file_renaming_map": "!renaming_map.json",
  "files_mask": "*.jpg",
  "ffmpeg": "ffmpeg.exe",
  "ffmpeg_video_encoder": "libx264",
  "ffmpeg_input_framerate": 1
}
```

## Использование
1. Установите AutoHotkey: https://www.autohotkey.com/.
2. Запустите `TakeScreenshotLoop.ahk` вручную или добавьте его (или ярлык) в автозапуск.

### Добавление в автозапуск (Windows)

- Для текущего пользователя: Win+R → введите `shell:startup` → поместите файл/ярлык туда.
- Для всех пользователей (нужны права администратора): Win+R → `shell:common startup` → поместите файл/ярлык туда.


 - Найти файл в провдоднике, отметить, нажать Control+C.
 - Нажать Win+R, откроется окно запуска команд (Run dialog), набери `shell:startup` и кликни OK или нажми Enter. 
Откроется папка автозапуска текущего пользоавтеля.
Чтобы открыть папку автозапуска для всех пользователей набери `shell:common startup` (для этого нужны права админитстратора).
 - Удерживая клавишу Shift кликнуть правую мыши и кликнуть на "Paste Shortcut". Должен появиться соответвующийй ярлк.
 
 Windows 11 All Users. Папка автозапуска для всех пользоввателей: `%ProgramData%\Microsoft\Windows\Start Menu\Programs\StartUp`

 Windows 11 Current user. Папка автозапуска текущего пользователя: 
 `%AppData%\Microsoft\Windows\Start Menu\Programs\Startup`

### Создание видео. Запуск `make_video.py` / `make_video.exe
- Для `make_video.py`: убедитесь, что Python 3.6+ и ffmpeg установлены и доступны в PATH.
- Для `make_video.exe`: Python не требуется, но ffmpeg всё ещё должен быть установлен и доступен в PATH.
- По умолчанию скрипт/экзешник ожидает, что рядом с ним (или в текущей рабочей директории) есть папка `sshots/` с подпапками по датам.
- Рекомендуется запускать скрипт из каталога репозитория, например:
  - Откройте PowerShell в папке с репозиторием и выполните: `python make_video.py`
  - Или просто запустите `make_video.exe`
- Результат: в каждой обработанной подпапке создаётся `!output.mkv`.

### Что делает `make_video.py`
- Проходит по подпапкам в `sshots/` (по умолчанию пропускает подпапку текущего дня).
- Создаёт временный файл субтитров `!output.srt`, переименовывает изображения в последовательность `0000.jpg, 0001.jpg, ...`, запускает ffmpeg для сборки `!output.mkv`, затем восстанавливает оригинальные имена изображений.
- В результате остаются временные/технические файлы: `!output.mkv`, `!output.srt`, `!renaming_map.json` — это нормально (см. код).
